# ENTimate

Приложение для учёта количества документов: карточки документов, пациенты, связи между ними и отчёты. Все данные хранятся локально на устройстве.

## Установка

Скачайте последнюю версию APK со страницы релизов:

- https://github.com/EsterNull/ENTimate/releases/latest

Перед установкой на Android 8+ потребуется один раз разрешить установку приложений из неизвестных источников — система сама предложит это сделать.

## Обновления

В приложении есть встроенная проверка обновлений: «Настройки → Проверить обновления». Приложение сравнивает текущую версию с последним релизом на GitHub, при наличии новой версии скачивает APK самостоятельно (без браузера) и передаёт его системному установщику — останется только подтвердить установку.

## Возможности

- Карточки документов и учёт их количества
- Пациенты с основными и пользовательскими полями (включая диагноз и дату выписки)
- Связи «поле пациента → документ» с автоматическим пересчётом количества и историей изменений
- Переоформление пациентов и выписка
- Документные отчёты с экспортом в DOCX/PDF
- Табличные отчёты с экспортом в XLSX/CSV/PDF
- Резервное копирование данных (экспорт/импорт JSON)
- Пользовательские поля, темы оформления, формат даты

## Автосборка (GitHub Actions)

При пуше в ветку `master`/`main` срабатывает workflow `.github/workflows/release-apk.yml`: он сравнивает версию из `app/build.gradle.kts` с тегом последнего релиза и, если она отличается, собирает APK и выпускает новый релиз под тегом этой версии. Запуск можно также выполнить вручную (вкладка Actions → Release APK → Run workflow).

Для стабильных обновлений (чтобы подписи APK совпадали между релизами) задайте в секретах репозитория:

- `ANDROID_KEYSTORE_BASE64` — keystore в base64
- `ANDROID_KEYSTORE_PASSWORD` (необязательно, по умолчанию `android`)
- `ANDROID_KEY_ALIAS` (необязательно, по умолчанию `androiddebugkey`)
- `ANDROID_KEY_PASSWORD` (необязательно, равен паролю keystore)

Без секретов APK подписывается временным debug-ключом: устанавливается, но обновляться поверх предыдущих сборок может не будет.

## Сборка

Требуется Android SDK и JDK 17.

Разработка:

```
gradlew.bat :app:assembleDebug
```

Сборка и подпись релизного APK (создаёт `app/build/outputs/apk/release/ENTimate.apk`):

```
build_release.bat
```
